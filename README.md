# Kinetic CA Template

A modern, high-performance web template tailored for Chartered Accountants, corporate compliance advisors, and tax practices.

## Features
- Pine green & mint animated visual aesthetics
- Word-by-word animated headline & drawing growth chart
- Responsive service bento grid & practice advisory desks
- Filterable statutory tax due dates calendar
- Interactive tax & financial calculators
- ICAI compliance standards & practice credentials about section
- Lead callback consultation forms
